# مُعين مدرستي — وكيل تقارير ذكي لمنصة مدرستي

إضافة Chrome / Edge (Manifest V3) تقرأ ما يظهر للمعلم أو القائد في منصة مدرستي (`schools.madrasati.sa`)، وتحلله، ثم تُخرج تقارير عربية قابلة للطباعة بهوية وزارة التعليم. **تعمل على الجهاز فقط**: لا خوادم، ولا نماذج لغوية خارجية، ولا تحميل لأي كود.

## ما الذي تفعله

| المرحلة | التفاصيل |
|---|---|
| **الاكتشاف** | تمسح الصفحة دون محددات خاصة بالمنصة، فتعمل مع أي مدرسة وتتحمل تغيّر تصميمها: جداول HTML (مع `rowspan`/`colspan` والرؤوس متعددة المستويات)، والشبكات بأدوار ARIA، والبطاقات المتكررة (مثل بطاقات نشاط المعلمين)، والإطارات من النطاق نفسه، إضافةً إلى **الاختيار اليدوي** بالنقر. |
| **الفهم** | تصنّف الجدول: درجات، حضور، واجبات، نشاط معلمين، اختبارات. وتصنّف كل عمود: اسم، رقم هوية (لا يُحسب درجةً)، تسلسل، درجة، حالة، تاريخ. تفهم الأرقام الهندية والكسور (`17/20`) والنسب، والأيقونات (✓ ✗ وأيقونات Font Awesome) وخانات الاختيار. |
| **التحليل** | الدرجة العظمى من العنوان `(15)` أو من الخلية أو بالتقدير مع تنبيه صريح، والنسبة الموزونة لكل طالب، والتقديرات، ونسبة النجاح، والوسيط، والانحراف المعياري، ونسب الغياب وعدم التسليم، ومؤشر نشاط المعلمين. |
| **الاستنتاج** | محرك قواعد محلي شفاف يكتب الملاحظات والتوصيات بالعربية: المتميزون، ومن هم دون الحد الأدنى، ومن يحتاج دعمًا، وأضعف أداة تقويم، والرصد الناقص، والغياب المتكرر، والمعلمون بلا نشاط. كل رقم محسوب من الجدول نفسه دون تضخيم. |
| **التقرير** | ترويسة قابلة للتحرير (هجري وميلادي)، ومؤشرات، ورسوم، وقراءة تحليلية، وقائمة متابعة بعمود «الإجراء المتخذ» عند الطباعة، وترتيب النتائج، والبيانات الكاملة قابلة للفرز، وتوقيعات، و**بطاقة فردية لكل طالب** لإشعار ولي الأمر. طباعة A4 أو PDF، وتصدير CSV يفتحه Excel بالعربية. |
| **التجميع** | البيانات المقسّمة على صفحات أو الموزعة بين صفحات (درجات + حضور) تُدمج في «مجموعة» بعمود الاسم دون تكرار. |

## التثبيت (وضع المطوّر)

1. افتح `chrome://extensions` (أو `edge://extensions`) وفعّل **وضع المطوّر**.
2. اختر **تحميل إضافة غير مضغوطة** وحدد مجلد `extension/`.
3. افتح منصة مدرستي، ثم اضغط الزر العائم أسفل يسار الصفحة أو أيقونة الإضافة.

## الخصوصية (مبدأ غير قابل للتفاوض)

- الصلاحية الوحيدة `storage`، والسكربت يعمل على `*.madrasati.sa` فقط.
- سياسة أمان المحتوى لصفحات الإضافة: `connect-src 'none'`، فلا يمكن لأي صفحة فيها الاتصال بالشبكة.
- بيانات التقرير المفتوح تُمرر عبر `chrome.storage.session` (في الذاكرة، تُمسح بإغلاق المتصفح، ولا تصل إليها صفحات الويب).
- المجموعات المحفوظة في `chrome.storage.local` تُحذف تلقائيًا بعد مدة يحددها المستخدم (30 يومًا افتراضيًا)، ومن الإعدادات يمكن حذف كل شيء بضغطة.
- اختبار المتصفح يفشل إن حاولت الإضافة أي طلب شبكي خارجي.
- لا تُبنى أي واجهة بـ `innerHTML` من بيانات الصفحة، ويُحمى تصدير CSV من حقن الصيغ.

## الهوية البصرية

ألوان دليل هوية وزارة التعليم (الإصدار الثالث 2025)، وصناديق العناوين بنمط الدليل (الكلمة الأولى عريضة)، والتدرج الرسمي، والأرقام اللاتينية. الخط الرسمي «Helvetica Neue W23 for SKY» يُستخدم إن كان مثبتًا على الجهاز، وإلا فالبديل IBM Plex Sans Arabic ثم خطوط النظام (لا يُحمَّل أي خط من الإنترنت). شعار الوزارة **معطّل افتراضيًا** ويُفعَّل من الإعدادات للتقارير الرسمية الصادرة عن المدرسة، لأن الإضافة أداة مستقلة غير تابعة للوزارة.

## البنية

```
manifest.json
src/lib/numbers.js      تطبيع العربية والأرقام (نقي)
src/lib/analyzer.js     تصنيف الجداول والأعمدة والإحصاءات (نقي)
src/lib/insights.js     محرك الاستنتاجات والتوصيات (نقي)
src/lib/data.js         CSV والدمج (نقي)
src/lib/extractor.js    قراءة الجداول من DOM
src/content/            الزر العائم واللوحة (Shadow DOM)
src/report/             صفحة التقرير القابلة للطباعة
src/options/            الإعدادات والخصوصية
src/background/         فتح التقارير
tests/                  اختبارات الوحدات + اختبار متصفح بصفحات محاكاة
```

## الاختبارات

```bash
cd extension
npm test                 # اختبارات الوحدات (Node 18+)، بلا اعتماديات
npm run test:e2e         # يحتاج Playwright وChromium
```

صفحات `tests/fixtures/` **محاكاة** لأنماط شائعة (جدول درجات برؤوس مدمجة وأرقام هندية، وشبكة حضور بأيقونات، وبطاقات نشاط معلمين)، وليست نسخًا من المنصة. لرفع الدقة على صفحات مدرستي الفعلية: احفظ الصفحة (Ctrl+S) **بعد حذف أسماء الطلاب وأرقام هوياتهم أو استبدالها**، وضعها في `tests/fixtures/`، وأضف لها حالة في `tests/e2e.js`.

## حدود معروفة

- يقرأ ما هو معروض فقط. الجداول المقسّمة على صفحات تحتاج «عرض الكل» أو التجميع صفحةً صفحة.
- الدرجة العظمى المقدّرة تقريبية، ويُنبَّه عليها في التقرير، وتُصحَّح من «إعدادات الأعمدة».
- حدود التقديرات الافتراضية (90/80/70/50) قابلة للتعديل لتطابق لائحة التقويم المعتمدة للمرحلة.
